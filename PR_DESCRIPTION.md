## Goal

Take SPECTRE (open CT ViT, ~0.4B) through:

1. CPU smoke of `spectre embed` (no CUDA required).
2. ViT backbone export → ONNX → OpenVINO IR (CPU; Xeon/Arc iron later).
3. Cosine agreement of backbone embeddings vs the torch reference path.
4. One-command latency + peak RSS bench (**labeled box-only / non-target**).

Stop at **embeddings** (no segmentation / product packaging).

## Upstream entry points

- CLI: `spectre embed <scan.nii.gz> --device cpu` (public docs often show `--device cuda`; CPU works via `--device cpu` / `auto`).
- Optional extra `gds-cuda12` is CUDA-12-only and **not** needed for this path.
- Weights: Hugging Face `cclaess/SPECTRE-Large` / preset `spectre-large`.

## Changes in this branch

1. **`src/spectre/utils/modeling.py`** — Hub pickle `.pt` load under `huggingface_hub>=1.x` (`safe=False` + `weights_only` fallback). Without this, `spectre embed` fails on current Hub clients with “Cannot load … as safetensors”.
2. **`scripts/openvino_cpu/`** — synthetic CT, export, cosine agree, embed bench, `run_all.sh`.
3. **`requirements-cpu-openvino.txt`** — pinned CPU torch/ORT/OpenVINO set.
4. **`PR_DESCRIPTION.md`** — this document (NC callout).

## Results (box — **box-only / non-target**)

Hardware: shared Linux agent box, **no NVIDIA GPU**, OpenVINO devices=`CPU` only. Not Xeon-tuned, not Arc.

| Step | Status |
|------|--------|
| MIT code + CC-BY-NC-SA weights verified | OK |
| `spectre embed --device cpu` on synthetic 128³×64 crop | OK (~1 crop, cls dim 1080) |
| ONNX export of backbone `forward_features` | OK (torch.onnx dynamo + legacy) |
| OpenVINO IR compile (CPU) | OK |
| Cosine torch↔ORT | ≈ **1.0** (max abs ~1e-4) |
| Cosine torch↔OV with `INFERENCE_PRECISION_HINT=FP32` | ≈ **1.0** (max abs ~5e-5) |
| Cosine torch↔OV **default** precision | **degraded** (BF16-ish; document FP32 requirement) |

Exact numbers are regenerated by `bash scripts/openvino_cpu/run_all.sh` into `artifacts/ov/cosine_report.json` and `artifacts/bench/embed_bench.json`.

### Precision blocker (mitigated, not a hard stop)

OpenVINO CPU **default** inference precision can drop cosine to ~0.7–0.9 on this RoPE 3D ViT. **Fix:** compile with `INFERENCE_PRECISION_HINT=FP32` (and save IR with `compress_to_fp16=False`). Documented in `scripts/openvino_cpu/README.md` and `agree_cosine.py`.

Arc: not exercised on this box (no GPU device in `ov.Core().available_devices`). Same IR should be recompiled with `GPU` / Arc on target iron.

## How to reproduce

```bash
python -m venv .venv && source .venv/bin/activate
pip install -U pip wheel
pip install torch==2.10.0+cpu torchvision==0.25.0+cpu \
  --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements-cpu-openvino.txt
pip install -e ".[inference]"
bash scripts/openvino_cpu/run_all.sh
```
